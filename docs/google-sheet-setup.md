# 팀 기록(구글 시트 + PIN) 설정하기

한 번만 하면 돼요. 10분 정도 걸려요. 끝나면 웹 앱 주소 하나만 사이트에 넣으면 돼요.

## 이 설정으로 생기는 것

- 시험지를 제출하면 채점 결과 위에 **팀 기록에 보내기** 버튼이 생겨요.
  - 처음 누를 때 숫자 4자리 PIN을 정해요.
  - 보내는 내용은 **이름, 주차, 문제 번호, 맞음/틀림**뿐이에요.
- **내 오답 노트**(`notes.html`)는 이름과 PIN으로 어느 기기에서나 열려요.
- **팀 정답률**은 한 주에 3명 이상 보내면 나타나요.
  - 시험지 해설 위, 홈의 "이번 주 차례" 책등, 오답 노트의 "다 같이 어려웠던 문제"에 보여요.
  - 이름 없이 합계만 보여요.
- 시트는 승환님만 열 수 있어요. 스터디원은 사이트를 통해 자기 기록만 볼 수 있어요.

## 1. 구글 시트 만들기

1. 승환님 구글 계정으로 https://sheets.new 를 열어요.
2. 왼쪽 위 제목을 `스터디 복습 퀴즈 팀 기록`으로 바꿔요.
3. 시트 공유는 하지 않아요. 탭(`results`, `pins`)은 코드가 처음 실행될 때 알아서 만들어요.

## 2. 코드 붙여 넣기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
2. 새 창 왼쪽의 `Code.gs`를 열고 안에 있는 내용을 모두 지워요.
3. 이 저장소의 `apps-script/Code.gs` 내용을 전부 복사해 붙여 넣어요.
   - GitHub에서는 https://github.com/spider3792-ux/KT_AIVLE_T/blob/master/apps-script/Code.gs 의 **Raw** 버튼을 누르면 복사하기 쉬워요.
4. 위쪽 디스크 아이콘(프로젝트 저장)을 눌러요.

스터디원 이름이 바뀌면 코드 맨 위 `MEMBERS` 줄도 `members.json`과 똑같이 고쳐 주세요.

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 골라요.
3. 아래처럼 채워요.
   - 설명: `팀 기록`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 눌러요.
5. 권한 요청이 나오면 진행해요.
   1. **액세스 승인 → 내 계정 선택**을 눌러요.
   2. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않은 페이지)로 이동**을 눌러요.
   3. **허용**을 눌러요.
   - 승환님이 직접 만든 스크립트라서 나오는 확인 화면이에요. 이 스크립트는 이 시트만 읽고 써요.
6. **웹 앱 URL**을 복사해요.
   - `https://script.google.com/macros/s/…긴 글자…/exec` 모양이에요.
   - 이 주소를 브라우저에 붙여 넣어 열었을 때 `{"ok":true,"service":"study-review-quiz"}`가 보이면 성공이에요.

## 4. 사이트에 주소 넣기

둘 중 하나를 고르면 돼요.

- **Claude Code에 맡기기:** 웹 앱 URL을 보내 주면 `config.json`에 넣고 사이트에 올려요.
- **직접 하기:** 저장소의 `config.json`을 아래처럼 고친 뒤 커밋·푸시해요.

  ```json
  {
    "sheetUrl": "https://script.google.com/macros/s/…/exec"
  }
  ```

1~2분 뒤 사이트를 새로고침하면 새 기능이 켜져요. 주소가 비어 있으면 지금처럼 각자 브라우저에만 저장돼요.

## 자주 생길 일

- **PIN을 잊었어요.**
  - 시트의 `pins` 탭에서 그 사람의 줄을 지워 주세요.
  - 다음에 보낼 때 새 PIN을 정하게 돼요. 이미 보낸 기록은 그대로 남아요.
- **PIN을 5번 틀려서 잠겼어요.** 15분 뒤에 다시 열려요.
- **잘못 보낸 기록을 지우고 싶어요.**
  - `results` 탭에서 그 이름과 주차의 줄을 지워요.
  - 그 사람의 브라우저에는 "보냈어요" 표시가 남아 있으니, 다시 보내야 하면 알려 주세요.
- **코드를 고쳤어요.** 다시 배포할 때는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 눌러요. 그래야 웹 앱 URL이 그대로 유지돼요.
- **이미 제출한 지난 시험지도 보낼 수 있어요.** 그 시험지를 다시 열면 채점 결과 위에 "팀 기록에 보내기" 버튼이 있어요.
