  <action>
Wire ONE path end to end: a date goes in, the window and week id come out, through the pure core, the CLI, and the npm script, checked by a real spawn of the CLI against the real quizzes/ folder.

1. scripts/lib/week-core.mjs, pure (no fs, no process, no local-time Date): all date arithmetic uses UTC midnight `YYYY-MM-DDT00:00:00Z`. Export:
   - `kstToday(nowMs)`: the KST calendar date (YYYY-MM-DD) of a millisecond timestamp, by adding 9 hours and reading the UTC date (Korea has no daylight saving). Default argument is Date.now().
   - `addDays(ymd, n)`: YYYY-MM-DD shifted by n days (negative allowed).
   - `fridayOnOrBefore(ymd)`: the latest Friday on or before the date (a Friday returns itself).
   - `isoWeekId(ymd)`: the ISO-8601 week id `YYYY-Www`. Method: move the date to the Thursday of its ISO week (Monday-first weeks); the id's year is that Thursday's year; the week number is 1 + floor((day-of-year of that Thursday - 1) / 7), zero-padded to two digits.
   - `computeWindow(today)`: returns `{ today, isFriday, from, to, weekId }` where `to = fridayOnOrBefore(today)`, `from = addDays(to, -7)`, `weekId = isoWeekId(to)`, `isFriday = (to === today)`. Throws an Error whose message starts with the Korean stem `날짜 형식이 올바르지 않습니다 (YYYY-MM-DD, 현재 X)` when `today` fails `isRealDate` (import isRealDate from ./validate-core.mjs so the date rule is the checker's).
   The window is inclusive on both ends and 8 calendar days wide (Friday to Friday), matching the sample set's range 2026-10-09 ~ 2026-10-16.

2. scripts/week.mjs, thin CLI: `node scripts/week.mjs [--today YYYY-MM-DD] [--json]`. Default today = kstToday(Date.now()). Mirror validate-quiz.mjs structure: Exit class, parseArgs, main, a top-level try/catch that prints the Korean message to stderr and sets process.exitCode. Exit 0 on success; exit 2 for an unknown option, a `--today` with no value or a value that is not a real date (print the Korean usage line plus the message). With `--json` print `JSON.stringify(report, null, 2)` where report has exactly these keys in this order: `today`, `isFriday`, `window` ({ from, to }), `weekId`, `previous`, `notes`. This task emits `previous: null` and `notes: []`; the previous-set lookup and the Korean notes arrive in Task 2 without changing the shape. Without `--json` print three Korean lines: `기준 날짜(KST): <today> (<요일>)`, `출제 범위: <from> ~ <to>`, `주차 id: <weekId>`.

3. package.json: add the script `"week": "node scripts/week.mjs"` (place it after `smoke`). Do not touch `check`, `test`, `validate`, `lint:design`, and add no dependencies or devDependencies.

4. tests/week.test.mjs (node:test + node:assert/strict), the tracer group only: spawn `process.execPath` with `scripts/week.mjs --today 2026-10-16 --json` from the repo root, parse stdout, and assert `today` is 2026-10-16, `isFriday` is true, `window` is { from: 2026-10-09, to: 2026-10-16 }, `weekId` is 2026-W42 and `previous` is null (the sample set 2026-W42 is itself the target week, see Task 2).
